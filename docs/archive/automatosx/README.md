# AutomatosX Archive

This directory preserves historical AutomatosX planning artifacts, generated
reports, and superseded subsystem notes.

- [adr](adr/) - historical or subsystem-specific architecture decisions.
- [prd](prd/) - historical PRDs, implementation plans, and design notes.
- [reports](reports/) - phase reports, gap analysis, benchmarks, and status reports.

These files are retained for traceability. The current product direction is
defined by the canonical documents in:

- [Product Requirements](../../product/PRD.md)
- [Architecture Decisions](../../adr/ADR-0001-mac-first-cell-architecture.md)
- [Technical Specification](../../architecture/TECH_SPEC.md)
