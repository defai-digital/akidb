# Changelog

## v0.1.0

Initial public MIT release of AkiDB as a standalone project.

This release includes:

- Rust native engine with local segment storage, metadata, manifests, WAL, and compaction.
- TypeScript wrapper package.
- Optional Python binding.
- AkiDB-only contracts package.
- Vector, keyword, and hybrid search.

Notes:

- This is the initial split release from AX Fabric.
- Native package publishing and platform package automation are not finalized yet.
- The public API should be treated as early and subject to change before a future `v1.0.0`.
